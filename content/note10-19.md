# 关于配网

## IP地址

例：` 192.168.10.0 `

CRID形式：192.168.10.0

二进制形式：11000000.10101000.00001010.00000000

IP地址包含网络位与主机位
网络位就是购买的网段，用来指明整个网络上你的位置
主机位则用于分配给下发的各种设备，即用来给交换机下的各个电脑分发

### A类地址
网络位为前8位，取值范围为1~126，可容纳16777214台设备
127不可用

### B类地址
网络位为前16位，取值范围为128~191，可容纳65534台设备

### C类地址
网络位为前24位，取值范围为192~223，可容纳154台设备

### D类为组播地址 224.0.0.0-239.255.255.255
### E类为未来保留 240.0.0.0-247.255.255.255

越往前越网络位所占位置越少，也就能容纳更多主机位（设备），也更贵

## 子网掩码

子网掩码的作用是指出一个IP地址中哪一些是网络地址，哪些是主机地址

CRID形式：192.168.10.0
子网掩码：255.255.255.0

合并简写：192.168.10.0/24
方式：
IP地址 / 网络位所占的位数
总共有32位，看网络位占了多少即可,例如上面就占了三分之二的空间，也就是24位



### CRID转二进制方法换算方法：

在八位二进制中，使用这8个数：进行相乘后求和，例如168：

128  64  32 16 8 4 2 1

1   0  1 0  1  0  0  0   

128  +  32  +  8      =  168
