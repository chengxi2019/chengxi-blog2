## 按键门铃电路，按键按下，蜂鸣器发出叮咚声，LED发光  
蜂鸣器同样为低电平有效  
蜂鸣器分为：  
- 有源蜂鸣器，无需编程，有电就响声  
- 无源蜂鸣器，需编程，未编程有电也无响声  

### 单按键  
``` c
#include <reg52.h>
sbit beep = P2^5;
sbit key1 = P3^1;
sbit led = P2^0;

bit flag;
void delay(unsigned int t)
{
    int i,j;
    for(i=t;i>0;i--)    
        for(j=100;j>0;j--){}    
}
void doorbell(unsigned char t)
{
    unsigned int i,j;
    for(i=0;i<800;i++)
    {
        beep= ~beep;
        for(j=0;j<t;j++);
    }
}
void KEY_FUN()
{
    if(key1==0)
        delay(10);
    if(key1==0)
    {
        flag=1;
        led=0;
        doorbell(60);
        doorbell(75);
        delay(500);
        led = 1;
        flag = 0;
    } while(!key1);
}


void main()
{
    flag=0;
    while(1)
    {
        KEY_FUN();
    }
}
```
