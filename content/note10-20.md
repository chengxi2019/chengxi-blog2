### 更改文件所有者（权限）
通常需要使用 sudo 配合
chown 被给与权限用户 / :组名 文件名
``` bash
chown ubuntu aa.c

chown root aa.c
```
root也就是超级用户
也允许一次性执行两次:
`chown ubuntu:root aa.c`

### 在特定位置下寻找特定文件
find 路径 -name 文件名
`find /etc -name "passwd"`

### tar打包文件
tar -cvf 包名.tar 被压缩文件

### 查看压缩包内容
tar -tf 包名

### 解压缩
tar -xvf 包名

### 解压至指定位置:
tar -xvf 包名 -C 路径

附：解压路径为空时默认解压至当前目录，
    -C必须为大写，
    仅-cvf为打包而不压缩，压缩需gzip或bzip配合

## tar拓展:

### 使用gzip压缩：

`tar -czvf 包名.gz 被压缩文件`

### 使用bz2压缩：

`tar -cjvf 包名.bz2 被压缩文件`

附注：使用 *chmod* 改权限时，a+rwx 之间*没有*空格
