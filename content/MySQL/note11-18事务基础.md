### 事务作用:

事务，即是把多条 SQL 打包成一个“要么全部成功，要么全部失败回滚”的不可分割的执行单元，以保证数据的一致性  

比如：执行转账操作时，需要同时满足 A 扣 100 元、B 加 100 元。这两步要么全部完成，要么全都不做。只有在最后 COMMIT 提交，数据才真正生效；若中途出错，还能 ROLLBACK 撤回操作，防止数据错乱  

|关键词|作用|
|:---|---:|
|START TRANSACTION|开始事务|
|ROLLBACK|撤回|
|COMMIT|提交|
### 事务使用过程
``` sql
START TRANSACTION;   --开始事务

-- 操作区,语句执行后未真正生效
UPDATE account
SET balance = balance + 500
WHERE account_id = 'A001';

--    二选一：

ROLLBACK;   --如有误，执行可撤回更改

COMMIT;   --执行后更改真正生效
```
