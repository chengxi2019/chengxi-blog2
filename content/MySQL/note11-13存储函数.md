# FUNCTION存储函数

作用：函数就是接受参数，经过计算后，必须返回一个具体结果  
函数与过程最直接的不同处：**函数必须有返回值**  
函数可以与数据一齐传入字段中，例如`get_award(480)`,此时需要将数据写入()内    
>示例函数名为add5，根据需要决定函数名

### 创建函数(考)  
``` sql
delimiter //
CREATE FUNCTION add5(score INT)
RETURNS INT
DETERMINISTIC NO SQL
BEGIN 
	RETURN score + 5;
END 
//
delimiter ;
```
>必须严格对应，严记各个分号的位置  

### 使用函数:  
分两种情况：  
- **单独**使用：`SELECT add5(472)`  
	单独使用时仅需与`SELECT`配合使用即可

- 在select列表中使用：
	将函数放在SELECT处，并将数据传入函数  
	``` sql
	SELECT student_id,entrance_score,add5(entrance_score) as outcome FROM student
	WHERE student_id IN ('S001','S002','S003')
	ORDER BY student_id ASC
	```

>查删部分与存储过程相同  
### 展示所有存在的函数
`SHOW FUNCTION STATUS;`

### 展示初建时的完整 SQL 语句  
`SHOW CREATE FUNCTION add5;`  

### 删除函数  
`DROP FUNCTION add5`

## IF结构的函数
格式：
``` sql
BEGIN
  IF score > 500.0 THEN RETURN 3000;
  ELSEIF score > 480 THEN RETURN 2000;
  ELSE RETURN 0.00;
  END IF;
END //
```  
切记：末尾两个`END`表示不同的结构结束
