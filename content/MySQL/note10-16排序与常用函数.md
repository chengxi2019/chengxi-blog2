## 排序与截取

### 排序 ORDER BY  

作用：可同时对多个字段排序，靠前的字段优先排序  
ASC升序，DESC降序，未指定排序方式时默认为升序  
格式：`orderby 字段 排序方式`  
 
``` sql
SELECT * FROM `student5`
ORDER BY entrance_score DESC,scholarship ASC;
```

### 分页并截取结果 LIMIT  

作用：跳过指定数量数据，从此处向后查看数据  
格式：`limit 跳过的行数, 需要取出的行数`  
例如：limit 5,10 意思为：从**第6行**开始(包括第6行)，向后取10行数据  
此语句在order by存在时必须要写在order by后  
其他用法：  
`limit 10`:仅查前10条数据  
``` sql
SELECT * FROM `student5`
limit 5,10;
```

## 常用函数

几乎所有的聚合函数都写在select后from前！！！  

### 截取字段 SUBSTRING

作用：按需截取数据  
格式：`substring (字段,开始位置,结束位置)`  
例如下方例子：当class_name为'软件3班'时，(1,2)会返回'软件'  
``` sql
SELECT SUBSTRING(class_name,1,2) FROM student5
```

### 平均值 AVG

作用：取数据平均值  
格式：`ROUND(AVG(字段),保留小数位)`  
>其中：round()用于控制小数点，avg也可单独使用，只是出题往往会在一起  
``` sql
SELECT ROUND(AVG(entrance_score),1) FROM student4
```  

### 日期：年份与月份 YEAR MONTH

作用：取数据中的日期  
格式：年份与月份：  
`YEAR(birth_date)`  
`MONTH(birth_date)`  
>不符合的数据返回NULL  
``` sql
SELECT YEAR(birth_date),MONTH(birth_date) FROM student4
```

### 条件判断 IF

作用：根据条件是否成立，从两个给定的结果中二选一返回，成立返回前者，不成立返回后者   
格式：`IF(字段 条件,'真值','假值')`  
``` sql
SELECT IF (scholarship > 1000,'>1000','<1000') FROM student4
```

### 多条件判断 CASE

作用：belike编程语言中的'switch'  
格式：(Navicat中输入case似乎能够补全基本格式？)  
``` sql
CASE
    WHEN <条件1> THEN '结果1'
    WHEN <条件2> THEN '结果2'
    ELSE '默认结果'
END 
```
>else可以省略，如省略而又没有符合条件，则会返回NULL  
``` sql
SELECT 
CASE 
	WHEN scholarship > 1000 THEN '>1000'
    WHEN scholarship < 1000 THEN '<1000'  
	ELSE '我不知道'
END 
FROM student5
```

### 求和 SUM
作用：顾名思义  
格式：`SUM(字段)`  
>只能有一个字段！   
``` sql
SELECT SUM(entrance_score) FROM student5
```
