>格式中使用了小写的形式，正式写法仍使用大写  

### 排序 ORDER BY  

格式：`orderby 字段 排序方式`  
可同时对多个字段排序，靠前的字段优先排序  
ASC升序，DESC降序  
未指定排序方式时默认为升序  
``` sql
SELECT * FROM `student5`

ORDER BY entrance_score DESC,scholarship ASC;
```

### 分页并截取结果 LIMIT  

格式：`limit 跳过的行数, 需要取出的行数`
例如：limit 5,10 意思为：从**第6行**开始(包括第6行)，向后取10行数据  
其他用法：  
`limit 10`:仅查前10条数据
``` sql
SELECT * FROM `student5`

ORDER BY entrance_score DESC,scholarship ASC
limit 5,10;
```
