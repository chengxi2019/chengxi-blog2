## 存储过程
作用：把一段预先写好、需要完成多步操作的 SQL 逻辑打包存储在数据库里，之后通过 CALL 一键执行  

### IN类型
只进不出  
创建存储过程：    
``` sql
delimiter //
CREATE PROCEDURE get_student(IN p_id CHAR(4))
BEGIN
  SELECT student_id,student_name,major FROM student5
  WHERE student_id = p_id;
END //
delimiter ;
```

### OUT类型
只出不进  
创建存储过程：  
``` sql
delimiter //
CREATE PROCEDURE get_count(OUT p_count INT)
BEGIN
  SELECT COUNT(*) INTO p_count FROM student5;
END //
delimiter ;
```

### INOUT类型
需传入有初始值的变量，经过计算后再将新值带出  
创建存储过程： 
``` sql
delimiter //
CREATE PROCEDURE add_ten(INOUT p_num INT)
BEGIN
  SET p_num = p_num + 10;
END //
delimiter ;
```
>注意：sql中无法使用a+=b  

### 使用存储过程：
**IN类型**：
- **单独使用**格式：`CALL get_student('S014');`  
>IN 类型调用后，如果过程内部有 SELECT，会直接显示查询结果。
单独使用时，仅需与`CALL`配合使用即可  

**OUT类型**:  
- OUT类型**无法**单独使用！需先建立变量后再将结果传入变量再查询变量(2步)  
``` sql
CALL get_count(@count);	--先使用CALL创建变量，并向临时变量中传入存储过程的结果
SELECT @count;	--查询变量
```

**INOUT类型**
- INOUT类型**无法**单独使用！需先建立变量后再将结果传入变量再查询变量(3步)  
``` sql
SET @number = 20;	--先建立变量
CALL add_ten(@number);	--向变量中传入存储过程的结果
SELECT @number;	 --查询变量
```
**INOUT类型不允许在传入数据的同时才创建变量，需先创建变量**

>查删部分与存储函数相同  
### 展示所有存在的存储过程
`SHOW PROCEDURE STATUS;`

### 展示初建时的完整 SQL 语句  
`SHOW CREATE PROCEDURE get_student;`

### 删除存储过程
`DROP PROCEDURE get_student;`
