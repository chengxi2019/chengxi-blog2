#一、Linux 文件权限管理：chmod
基本语法
bash
chmod 用户 增减权限 具体权限 文件名
用户类型说明
符号	含义
u	所有者（user）
g	组用户（group）
o	其他用户（others）
a	所有用户（all）
权限类型说明
符号	含义
r	读权限
w	写权限
x	执行权限
常用示例
为所有用户增加所有权限：

bash
chmod a+rwx test
为其他用户减少写、执行权限：

bash
chmod o-wx test
数字方式设置权限（755）：

bash
chmod 755 test
755 表示：所有者拥有全部权限（rwx），组用户和其他用户拥有读与执行权限（r-x）。

#二、SQL 排序、分页与函数
1. 排序：ORDER BY
sql
ORDER BY entrance_score ASC
-- ASC 升序（默认），DESC 降序
多字段排序（靠前字段权重更大）：

sql
ORDER BY scholarship DESC, entrance_score DESC
2. 分页：LIMIT
sql
LIMIT 3
-- 返回结果中指定范围内的数据，一般置于语句末尾
组合使用——显示第一页的前三项：

sql
ORDER BY entrance_score DESC
LIMIT 0,3;
3. 常用函数
注意：函数写在 SELECT 中。

SUBSTRING —— 截取字段内容
sql
SELECT major, SUBSTRING(major,1,2) AS 专业简称
-- substring(字段, 开始位置, 结束位置)
ROUND —— 四舍五入保留小数
sql
SELECT entrance_score, ROUND(entrance_score/12,2) AS 每月奖学金
-- ROUND(数字, 保留小数位)：为负数则四舍五入到整数位
YEAR / MONTH —— 提取日期部分
sql
SELECT student_name, birth_date,
       YEAR(birth_date) AS 年份,
       MONTH(birth_date) AS 月份
IF —— 条件判断
sql
SELECT student_id, student_name, scholarship,
       IF(scholarship > 0,'有','无') AS 奖学金有无
-- IF(判断条件, 真值, 假值)
CASE —— 多条件分支（类似 switch）
sql
SELECT student_id, student_name, entrance_score,
      CASE
          WHEN entrance_score >= 500 THEN '优秀'
          WHEN entrance_score >= 480 THEN '良好'
          ELSE '继续努力'
      END AS score_level
语法结构：

sql
CASE
    WHEN 条件1 THEN '真值'
    WHEN 条件2 THEN '真值'
    ELSE 无符合条件值
END AS 表头名称
小结
主题	关键点
chmod	用户 + 增减 + 权限，支持符号与数字两种写法
ORDER BY	支持多字段排序，靠前字段优先级高
LIMIT	用于分页，常置于语句末尾
函数	写在 SELECT 中，可组合使用完成复杂逻辑
