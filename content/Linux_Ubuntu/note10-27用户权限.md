## 用户管理基础

- **查看当前用户**
  `whoami`

- **查看用户信息**
  `id username`  
  返回结果示例：`uid= gid= groups=`

- **查看用户配置文件**
  位置：`/etc/passwd`
  内容示例：`chengxi07:x:1000:1000:Chengxi07:/home/chengxi07:/bin/bash`
  > **字段解析（冒号分隔）**：用户名 : 密码占位符 : uid : gid : 备注 : 家目录位置 : 启动方式

- **切换至用户**
  `su username`

## 用户增删改与密码

- **新建用户 (`useradd`)**
  `sudo useradd username`
  - `-m`：自动创建用户家目录
  - `-s /bin/bash`：指定用户的默认 Shell

- **修改用户 (`usermod`)**
  `sudo usermod [选项] username`
  - `-m`：移动/创建用户家目录
  - `-s /bin/bash`：修改用户的默认 Shell
  - `-l`:更改用户名

- **删除用户 (`userdel`)**
  `sudo userdel username`
  - `-r`：递归删除（连同用户家目录和邮件一起删除）
  - `-f`：强制删除（即使用户当前已登录）

- **更改密码 (`passwd`)**
  `sudo passwd username`

>修改了登录方式为/bin/bash的，控制台用户名应为绿色

## 批量操作

- **批量建用户**
  建 01 到 05 共 5 个用户，自动建家目录并指定 shell：
  ```bash
  for i in {01..05}; do sudo useradd -m -s /bin/bash emp$i; done

- **批量改密码 (chpasswd)**
  不能单独使用，需配合 echo 管道符输入：
  ``` bash
  for i in {01..05}; do echo "emp$i:Init@2026" | sudo chpasswd; done
  ```
