## 组配置文件
位置：/etc/group  

文件内容查看方式：  
sudo:x:27:ubuntu,hypt,lisi  
组名：密码占位符：组编号：组内的用户名  

## 组相关命令

新增组：  
sudo groupadd name(组名)

删除组：  
sudo groupdel name(组名)

修改组：
sudo groupmod 选项 name(组名)
 - -n 更改组名
 - -g 更改组id

>gruop系类命令必须配合sudo使用  

## 将用户加入组方式*3

方式1，专属命令**gpasswd**  
`sudo gpasswd -a 组名 用户名`  
适用于用户与组已经存在的情况  
>-a为新添加

方式2:利用**useradd**  
`sudo useradd -g 组名 用户名`  
适用于用户不存在而组已存在的情况，一条语句可同时完成新建与入组
 
方式3，**usermod**修改用户进组  
`sudo usermod -aG 组名 用户名`  
-aG中的*G*必须要大写！！！  
>-a为新添加,而-ag便是新添加入组  

1~3的示例：  
``` bash
sudo gpasswd -a dev lisi
sudo useradd -g dev lisi
sudo usermod -aG sudo lis
```
