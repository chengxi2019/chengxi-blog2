# 通过SSH远程加密协议实现远程登陆

此方式适用于**Ubuntu控制台**，也同样适用于Windows**cmd**与**PowerShell**  

- 在控制台中输入:  `SSH 被登录用户名@IP地址`  
示例：`SSH ubuntu@192.168.10.10`

- 在返回的信息提示后按指示输入`yes`
>输入`yes`而不是输入`y`!!!

- 按指示输入被登录用户的密码

可以使用`whoami`查看当前用户已验证是否登陆成功
