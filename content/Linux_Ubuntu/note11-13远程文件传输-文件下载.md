## 远程文件传输scp

>此方式需要参与的设备处于同一网络环境下，即桥接  

### 传输单个文件
上传：`scp 文件 用户名@IP地址:/保存路径`  
下载：`scp 用户名@IP地址:/文件路径 保存位置`  

### 传输文件夹
上传：`scp -r 文件夹名 用户名@IP地址:/保存路径`  
下载：`scp -r 用户名@IP地址:/文件夹位置 保存位置`  

>下载就是上传反过来  
>文件夹传输就是加上 -r 递归  
>保存位置可以用 ./ 表示保存到当前控制台所打开位置

**示例**  
``` bash
scp zhangsan.txt ubuntu@同桌IP: /home/ubuntu
scp ubuntu@同桌IP:/home/ubuntu/zhangsan.txt ./

scp -r zhangsan  ubuntu@同桌IP:/home/ubuntu/
scp -r ubuntu@同桌IP:/home/ubuntu/zhangsan ./
```
